## BioChem
1. Intratesticular testosterone ~40–100× blood; exogenous T can sterilize by collapsing the local gradient (Coviello 2004; Jarow & Zirkin 2005).
2. By mass, women secrete more androgen than estrogen; ovarian estradiol from androgen via two-cell handoff (Burger 2002; Hillier 1994).
3. Post-glucose, blood lactate often rises before glucose — enteric→hepatic lactate shuttle (Brooks 2018; Hui 2017; Leija 2024).
4. Bicarbonate “bad” closed buffer at pH 7.4 yet best in vivo because lungs/kidneys open both ends.

## Cell Physics
1. Crowding slowdown is mostly collisional caging, not bulk viscosity (Swaminathan/Verkman 1997).
2. One cytoplasm, many viscosities by probe size (Kalwarczyk 2011); poroelastic short-time sponge (Moeendarbary 2013).
3. Metabolism fluidizes glass-forming cytoplasm (Parry 2014); ribosome/mTOR rheostat (Delarue 2018).
4. Geometry-controlled kinetics: start position can beat diffusivity (Bénichou 2010); osmotic crowding→gene output in seconds (Jalihal 2020).

## Receptors
1. OXTR-null prairie voles still pair-bond; milk let-down fails (Berendzen 2023).
2. Pair-bond phase = D2→D1 receptor switch in NAcc (Aragona 2006).
3. Male fertility needs ERα fluid reabsorption in efferent ducts.
4. Exact connection biology = density/circuit context; popular SNPs fragile; no human OXTR PET yet.

## Adipose
1. Androgen map color flips by sex (Frank/Palmer/Clegg 2019).
2. Menopause risk via depot ZIP-code shift, not only scale weight (Karastergiou 2012).
3. Adult fat-cell number largely set by late adolescence (Spalding 2008).
4. More SAT can be healthier than strained hypertrophy (Kim 2007; Scherer line).
