# Universal library & interactive body map

## Map-first content pipeline
1. Theme agents draft in `white-papers/`
2. Extract region copy, hover facts, and cards into `body-map/` and `library/`
3. Map UI consumes those payloads (build on open-source anatomy viewers when possible)

## Interactive body map
Hover / select shows:
- Organs
- Receptors
- Blood vessels
- Heart pumping
- Pressures inside veins
- Sex-specific layers (hormones, gonads, reproductive tracts)

Location: `body-map/`

## Universal human-body library
Everything real-life known, nicely configured. Categories include:
- DNA / genetics
- Diseases & disorders (lupus, cancer, …)
- Pressures
- Organs & systems
- Receptors
- Hormones & chemistry (incl. testosterone production and levels)
- Male reproductive system
- Female reproductive system
- Adipose / metabolism
- Bone metrics
- Whole-body anatomy

Location: `library/`
