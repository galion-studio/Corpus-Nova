# Lupus (systemic lupus erythematosus) — stub

**What it is:** An autoimmune condition where the immune system can attack multiple tissues (skin, joints, kidneys, more).  
**Systems often involved:** immune, integument, renal, musculoskeletal, cardiovascular.
