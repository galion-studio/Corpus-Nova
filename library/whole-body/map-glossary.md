# Map glossary — hover terms

Terms the interactive body map should expose on hover. Values are placeholders for seeding; replace with cited numbers as sources land.

| Term | What it means | Typical map reveal |
|------|---------------|--------------------|
| Organ | Named functional unit (e.g. heart, liver) | Outline + short role |
| Receptor | Protein that catches a chemical message | Pointer to Receptors library |
| Vessel | Artery / vein / capillary | Path highlight |
| Heart pump | Systole / diastole cycle | Simple pump GIF or cycle note |
| Vein pressure | Blood pressure in a named vein | Range (mmHg) when sourced |

See `library/pressures/` and `body-map/regions/` for structured data.
