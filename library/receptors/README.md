# Receptors — library index

**Owner:** Receptors theme (Theme 3). Whole Body links here from the map glossary.
**What a receptor is:** a protein that waits for one messenger molecule (its *ligand*) and changes the cell's behaviour when it binds. Every card here starts with a plain idea, then gives the exact name.

**Map-first:** Every card lists its **body-map tags**. These are region ids in `body-map/overlays/receptors-overlays.json`, so a hover on the map can open the card.
